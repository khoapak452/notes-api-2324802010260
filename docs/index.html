2. Năm đặc tính điện toán đám mây theo NIST

  1. On-demand Self-service - Tự phục vụ theo yêu cầu: Sinh viên tự tạo Codespace thông qua GitHub mà không cần quản trị viên cấp phát máy thủ công.
  2. Broad Network Access - Truy cập mạng rộng: API chạy trên Codespaces được truy cập từ máy tính và điện thoại thông qua đường dẫn HTTPS.
  3. Resource Pooling - Gộp tài nguyên: Codespaces cung cấp tài nguyên CPU và RAM từ hạ tầng đám mây dùng chung. Sinh viên sử dụng môi trường được cấp phát mà không cần sở hữu máy chủ vật lý.
  4. Rapid Elasticity - Co giãn nhanh: Khi tạo Codespace, sinh viên lựa chọn cấu hình máy 2-core. Nền tảng hỗ trợ thay đổi tài nguyên theo nhu cầu, tuy nhiên bài thực hành chưa thử tăng hoặc giảm cấu hình máy.
  5. Measured Service - Dịch vụ đo lường được: GitHub Billing Usage thống kê thời gian tính toán, dung lượng lưu trữ và chi phí sử dụng Codespaces. Tại thời điểm kiểm tra, số tiền phải thanh toán là 0 USD.
